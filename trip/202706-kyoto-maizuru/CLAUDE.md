- 使用者手動推到 GitHub Pages（公開 repo）。`index.html`、`js/`、`CLAUDE.md` 都會公開，任何人都看得到。

## 公開檔案不可寫入機敏資料

`index.html` 和 `CLAUDE.md` 都是公開的，寫入前先確認不含：

- 個人身分資料：姓名、護照號碼、生日、地址、個人電話、email。
- 訂位資料：訂位代號、確認號碼、電子機票號碼、WILLER／JR／飯店的個人訂位頁網址、QR Code 內容。
- 帳號密碼、API key、token、會員編號、信用卡資訊。
- 需要權限的私人檔案或文件內容（例：雲端硬碟裡的文件）。雲端硬碟資料夾連結可以放，使用者已設定存取權限；但不要把資料夾裡的檔案名稱或內容抄進來。

可以寫的：航班班號、日期、飯店名稱、店家與景點的公開電話和地址、官方網站與時刻表。
使用者如果提供上面不可寫的資料，先提醒會公開，問清楚再寫。
- 使用者狀態存在 `localStorage`（key `kyoto2027-state`）：語言、深淺色、方案選擇、清單勾選、捲動位置。

## 使用者偏好

**溝通**
- 檔案異動只限 `trip/202706-kyoto-maizuru/` 資料夾內。資料夾外的檔案（例：福岡版、repo 根目錄）不要直接改，要改先在對話中說明、跟使用者溝通。
- 發現問題時先用問答（AskUserQuestion）問使用者，不要直接改，除非使用者說「都修改」。
- 使用者說的事實要先查證再改（例：IC 卡能不能用，查官網後才改）。

**行程**
- 只用電車、巴士、步行，不排計程車。
- 宗教場所只排外觀或沿途經過，除非另外指定。
- 不寫「已訂」「確定可以訂」這類訂位狀態。
- 舞鶴市內走得到的路段（約 20–25 分鐘）以步行為主，巴士寫成「巴士備案」：當天可搭的班次、上車站名、付款方式。走不到的（三浜線往引揚記念館）才以巴士為主。
- 入住時間 = 下車時間＋步行時間，不可寫得比實際早。飯店離車站遠時，晚餐排在車站附近、入住之前。
- 巴士備案班次不可和前一個行程重疊（例：遊覽船 13:00–13:30 就不寫 13:25 的巴士）。
- 建議搭的全車指定席特急都要寫「先劃位」，包括西舞鶴 → 東舞鶴的まいづる和改搭的備案班次。
- 6/11 帶著行李逛伊勢丹，不寫置物櫃。
- 早上排購物時寫出店幾點開門、幾點要離開去搭車，不寫「不排某地」這類理由。

**連結**
- 機票、飯店不放預訂連結。
- 時間軸只在巴士、遊覽船、班次少的 JR 放時刻表連結；不放跳到確認清單的按鈕。
- 時間軸上要出示東西的步驟放 `SH(...)`：6/4 入境 → `vjw`、6/4 領周遊券 → `jr`、6/5 12:45 通過天橋立站剪票口 → `kuromatsu`、6/11 HARUKA → `westqr`、6/11 退稅海關確認 → `vjw`。
- 時刻表只用官方來源：JR 用 JR 西日本「JRおでかけネット」駅時刻表（`timetable.jr-odekake.net/station-timetable/<id>`，不帶日期參數，只能選約 6 週內日期）；巴士用京都交通官網路線頁的 PDF（`kyotokotsu.jp/route/`）。不用 Yahoo!、NAVITIME、Jorudan（Jorudan 手機版會導到登入頁）。
- 官網有繁中版就用繁中網址。
- 臨時才用得到的票券（かまぼこ手形）：連結放在買票那一步，時間軸只留一句，「哪些方案用得到」寫在當天備註（備註和 intro、TIPS 可用 `<b>`、`<br>`；時間軸文字不行）。

**版面**
- 確認清單放在最後；出示區放在提醒之前。
- 主色（紅）底上的文字用 `--on-accent`：淺色模式 `#fff`、深色模式 `#1a1210`（深色模式紅底白字看不清楚，使用者要紅底黑字）。新增主色底的按鈕、標籤時文字一律用這個變數，不要寫死 `#fff`。
- 天數顯示「第 N 日」（日文「N 日目」），不用「Day N」：資料寫 `n: L("第 1 日", "1 日目")`，範本用 `d.n[lang]`；內文提到別天也寫「第 2 日」／「2 日目」。
- 時間軸左邊的時間欄不能把詞拆開：`tParts()` 在「～」「〜」後切段，每段 `inline-block` 不換行（例：「上午～」「下午」各自一行，不會變成「上午～下」「午」）。
- 出示區只放固定卡片，不提供改網址、新增連結。順序：Visit Japan Web、WEST QR、JR 取票說明、黑松號取票說明（這兩張是說明頁，不是個人訂位頁）、Google 雲端硬碟（使用者放旅行文件的資料夾，`gdrive`）。
- 程式裡不留註解。
- 圖示一律用 Google Material Symbols Rounded（從 `fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/<name>/default/24px.svg` 取 path，`viewBox="0 -960 960 960"`、fill）。確認清單不顯示勾選框：點整張卡片切換，完成時標題前出現小 `check`、標題劃線、整張變暗。
- 視覺以原本簡潔風格為主，只保留：小圓角（卡片 8px、按鈕 4px、標籤 3px）、頁首右上青海波（`--seigaiha`，620px；淺色線條 `#d9a08f`、不透明度 0.25，深色 0.4；淺色原本太深蓋過文字）、淺色模式底色純色 `#faf8f4`（比原本米白淡一點；底色青海波太密、漸層看不清楚，都已拿掉）、Day 編號明朝體方形（內白框、不歪斜）、h2 下方細線、時間軸菱形節點＋移動段虛線。使用者覺得太花而拿掉和紙底紋、頁首直書、波紋線、h2 起筆線、清單分組菱形，不要再加回。

**資料與用字**
- 營業時間、票價、時刻都要上網查；查不到或資料舊的寫「出發前確認」並附版本（例：「2026/4/4 改正版」）。
- 自估的交通時間寫「約」。
- 京都交通 PDF 的 ※ 是「土日祝運休」，用旅行當天的星期對班次。
- 中文說明文字用台灣字形（三室戶寺、棧橋、田邊城跡），避免 Big5 沒有的日文字形在中文字體下顯示怪異；導航起訖、`map`、地址保留日文原字給 Google Maps 查詢。
- 用字統一：記念館（不寫紀念館）、巴士（不寫公車）、大人（不寫成人票）、舞鶴灣遊覽船、紅磚公園。
